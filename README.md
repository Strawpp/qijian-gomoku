# 棋间

一个把五子棋截图转成可继续下棋的网页，支持 15 路自由五子棋。图片识别、棋局保存和 Rapfi 算棋都在浏览器内完成。

- 好友跟盘时，先确认自己的实际落点，再录入好友的下一手。推荐点用虚线表示。
- 从截图、空盘或手动摆出的局面开始人机对弈。可以悔一步或悔一轮，任何模式都没有落子倒计时。
- 优先识别正面的游戏截图。自动定位失败时，可点选网格最外侧四角，也可以直接调整数字棋盘。
- 确认的棋局会随刷新恢复。用于核对的原图保留在当前页面，关闭或刷新后释放。

## 本地预览

在本目录运行 `node serve.cjs`，打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。首次克隆仓库后，需要先在有 Git、CMake 和 Emscripten 3.1.73 的环境里运行 `bash scripts/build-rapfi.sh`，生成引擎文件。页面、Worker 和引擎资源使用相对路径。

## GitHub Pages

在仓库的 **Settings → Pages** 将发布来源选为 **GitHub Actions**。推送到 `main` 后，工作流构建 Rapfi 并发布静态站点。
